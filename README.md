# Obsidian Ring

Brutal 90s arcade Mesoamerican ball sport built in Godot 4.6.2.

## Status

Initial EVAVO Studio game repository.

## Engine

- Godot 4.6.2
- GDScript/C# architecture to be determined during project bootstrap
- Desktop-first
- Controller and keyboard support
- Designed for later web/mobile compatibility where appropriate

## Development principles

- Original game, code, artwork, audio, characters, levels and branding
- Inspired by the design discipline and technical character of 1990s games
- No copied proprietary assets
- Deterministic and testable gameplay systems where practical
- Data-driven content
- Automated validation and local tooling
- No dependency on paid GitHub Actions or Vercel services
